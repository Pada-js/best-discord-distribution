# Best Discord

## Best Discord 1.1.4

**[Télécharger l’installateur Windows x64 — un seul EXE](https://github.com/Pada-js/best-discord-distribution/releases/download/v1.1.4/BestDiscord-Setup-1.1.4-x64.exe)**

Ferme complètement Discord, puis lance cet EXE. Pour une mise à jour ou une réparation, conserve le même dossier Best Discord afin de retrouver tes mods, réglages et sessions. Une installation neuve ne contient aucun mod ni compte.

La 1.1.4 regroupe le démarrage adaptatif après les mises à jour Discord, l’interrupteur global manuel, la sous-navigation des mods installés avec accès direct à leurs réglages, l’information vidéo au survol de la petite pochette et les corrections de redimensionnement et de démarrage du SDK. Le rendu cinéma continue sous les popups grâce au miroir local lorsque nécessaire.

Si une ancienne installation ne charge plus le menu Mods après une mise à jour Discord, utilise cet installateur par-dessus. La maintenance automatique prépare une réparation possédée pour un prochain lancement ; un lancement immédiat peut encore précéder son passage. Les mises à jour moteur sont préparées automatiquement lorsque le service est actif et appliquées après fermeture de Discord. Aucune compatibilité universelle avec toutes les futures mises à jour Discord n’est garantie.

## English

[Download the single Windows x64 installer](https://github.com/Pada-js/best-discord-distribution/releases/download/v1.1.4/BestDiscord-Setup-1.1.4-x64.exe). Close Discord first. Update or repair the same Best Discord home to preserve existing mods, settings and sessions; a new installation contains no mods or accounts.

1.1.4 includes adaptive startup, manual global ON/OFF, installed-mod sidebar navigation, fresh video information, native resize and SDK startup fixes. Background repair may need a later restart; future Discord changes can still require a new operator release. Automatic engine updates apply after Discord closes and remain subject to signed compatibility requirements.
