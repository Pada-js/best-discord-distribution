## YTMRP — YouTube Music 0.6.0

Dans Discord, ouvre **Mods → Catalogue → Actualiser** pour installer YTMRP, puis accorde explicitement les permissions et active le mod. Contrôle YouTube Music dans Discord, avec activité musicale, PiP et cinéma local.

## English

[Download the single Windows x64 installer](https://github.com/Pada-js/best-discord-distribution/releases/download/v1.1.0/BestDiscord-Setup-1.1.0-x64.exe). Double-click it; no manual extraction is needed. Close Discord before confirming installation. Fresh installations have no mods bundled. Install YTMRP from **Mods → Store → Refresh**, review its permissions, then enable it.

YTMRP controls YouTube Music in Discord, with music activity, PiP and a local cinema view. The regular Discord launcher is preserved. Existing mods and settings are retained during an upgrade.
