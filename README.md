# Best Discord

## Best Discord 1.1.1

**[Télécharger l’installateur Windows x64 — un seul EXE](https://github.com/Pada-js/best-discord-distribution/releases/download/v1.1.1/BestDiscord-Setup-1.1.1-x64.exe)**

Ferme Discord, puis lance cet EXE. Aucune extraction manuelle. Le lancement normal de Discord, les mods et leurs réglages sont conservés. Une installation neuve ne contient aucun mod ni compte.

Cette mise à jour du moteur maintient la vidéo cinéma animée derrière les profils et popups Discord. Le rendu natif est conservé quand il est dégagé ; le miroir intégré utilisé sous les popups est limité à 720p, cible 24 images/s. Les contenus protégés peuvent ne pas fournir de miroir.

## YTMRP — YouTube Music 0.6.0

Le paquet YTMRP reste inchangé. Dans **Mods → Catalogue → Actualiser**, installe YTMRP, accorde explicitement ses permissions, puis active-le. [Fiche et paquet YTMRP](https://github.com/Pada-js/best-discord-distribution/releases/tag/ytmrp-v0.6.0).
